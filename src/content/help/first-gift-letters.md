This page replaces the monthly pull from Database View (Mail, Donor Acknowledgement Letters) and the merge that followed. It lists the gifts Blackbaud has not acknowledged yet that are a partner's first gift and are coded to an acquisition appeal (the K codes, such as K254-GIFT). Each one gets a letter. A first gift of any size gets one, $5 included.

A first gift is the earliest gift credited to the partner and the spouse linked to them. A gift sent through a donor-advised fund counts for the partner it names. A second gift from the same partner is not a first gift, even when it carries a K code, so it stays on Receipts.

Every other waiting gift gets a printed receipt from **Receipts**. A first gift from an acquisition mailing gets its letter here and no receipt, so no gift is on both pages. The Receipts page lists these gifts under **Held back**, as **First-gift letter**, and does not offer them. A gift in a print file that is not marked yet is off both pages until the file is marked or thrown away.

## Steps

1. Open **First-gift letters** in Gifts. The totals show the letters to print, the first gifts waiting, the gifts held back, and the other waiting gifts that stay on Receipts. **Waiting for a first-gift letter** has a menu for how far back to look (30 to 365 days).
2. Every letter is ticked. Untick any you want to leave for later. **Find a partner** searches the list and **Open in Google Sheets** sends the rows to a sheet.
3. Pick the **Date on the letters** and **Signed by** (Carole Ward, Terry Goodman, Rachel Cox or Michael Hinton). Press **Make the print file**. A check reads every letter first for a ZIP that is not five digits, a state that is not a state, a street line with no number, a blank name after "Dear", and two records that look like one partner. **Needs a look** lists the flagged ones.
4. Press **Download the print file**. It is one PDF with a page per letter and a blank line for the signature. Print it, sign it and mail it.
5. Press **Mark as acknowledged in Blackbaud**, then **Yes, mark them**. Every gift in the file is acknowledged in Blackbaud on the date of the letters and leaves the list. Do this only after the letters are printed. If a gift is turned down, the same button tries it again.

Only one print file can be open at a time, and a Receipts print file and a first-gift print file cannot be made at the same moment. **Throw this print file away** puts the gifts back on the list when the letters were not mailed. It is not offered once any gift in the file is marked.

## The other tabs

- **Held back**: first gifts that get no letter, with the reason. A foundation, business or fund; a gift passed along for another partner; no mailing address; an address outside the U.S.; marked Do Not Mail, deceased or inactive. A gift fixed in Blackbaud comes back the next time the page loads.
- **Print files**: every file made, with its date, appeals, signer, who made it and whether it is marked. **Print file** downloads the same PDF again and **Open** shows it in a tab.
- **Letter wording**: the text of the letter, the closing, the greeting and the signer a new file starts with. {amount}, {fund} and {date} are filled in from the gift. The preview shows the letter as it will print. Saving changes only the files made afterward.

The starting wording is the regular thank-you letter with a welcome in the first sentence. Partner Care's own template is an InDesign file, so edit the text under **Letter wording** to match it. The FavorOS test user sees a made-up list and nothing it does reaches Blackbaud.
