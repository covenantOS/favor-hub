The page reads Blackbaud for every gift that has not been thanked yet and lays out one letter per partner, on the receipt paper.

## Steps

1. Open **Thank-you receipts** and put your name in **Your name**.
2. The totals at the top show how many letters are waiting and how many gifts they cover.
3. Under **Letters to print**, every letter is ticked. Untick any you want to leave for later. **Find a partner** searches the list.
4. Check the date for the letters and press **Make the print file**.
5. Open the proof first: every page drawn on a picture of the receipt paper. Look at the first few and the last few. Then print the file on the receipt paper.
6. Come back and press **Mark as thanked in Blackbaud**, then **Yes, mark them thanked**. Do this only after the letters are printed.

Only one print file can be open at a time. If you made the file, it shows on your Today page until it is marked.

## The other tabs

- **Held back**: gifts the file leaves out, with the reason, such as no mailing address, outside the U.S., marked deceased, asked for less mail, or a gift under $10. Where a letter should still go, press **Add a letter**. It changes to **Will print. Undo** so you can take it back.
- **Past printings**: every print file made, with its date, who made it and how many letters.
- **Letter wording**: the standard letter. Changes apply to the next print file.

## If something goes wrong

- **Made the file by mistake**: press **Throw this print file away** before marking. Nothing in Blackbaud changes.
- **Marking stopped partway**: open the page again. It finishes the marking where it stopped.
