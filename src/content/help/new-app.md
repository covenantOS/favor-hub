The new FavorOS app is the same FavorOS in a frame that stays on screen. The menu, the top bar, search, the bell and the Chat button load once, and moving between pages swaps only the page. Today, Mail and Chat are rebuilt inside it; every other page runs in the same frame as before.

## Turning it on

Open `dash.favorintl.org/?app2=1`. The choice is remembered on that browser. It is open to admins while it is tested. Admin, Settings holds two settings for it: which pages run in the new app and who may use it.

## Going back

Open the account menu (your initials) and press **Use classic FavorOS**. Nothing is lost either way: both versions read the same data.

## What is different

- Pages open without a full reload, and a page you come back to keeps its place.
- Chat opens inside the app, and the Chat button on every page shows the same messages and message box as the Chat page.
- The menu, the tabs across the top, search (Ctrl K), the bell and Help work the same as in classic FavorOS.

## If something looks wrong

Switch to classic FavorOS, then send Feedback from the page with a screenshot and say you were in the new app.
